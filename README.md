# 요양급여제공 기록 도우미

업무 중 손으로 적어 둔 메모를 사진으로 올리면, 수급자 개인별로
**신체활동 특이사항 · 인지관리 특이사항 · 상태변화 기록** 문장을 만들어 주는 웹 앱입니다.

만들어진 문장은 화면에서 바로 고칠 수 있고, **복사** 버튼을 눌러
[케어포](https://m.carefor.co.kr/share/care/care_list.php) 입력칸에 붙여 넣으면 됩니다.
앱이 케어포에 대신 입력하지는 않습니다.

## 쓰는 순서

1. **⚙ 설정** — Anthropic API 키를 한 번 등록합니다. (수급자 명단을 적어 두면 이름 표기를 맞춰 줍니다.)
2. **1단계** — 메모 사진을 올립니다. 여러 장을 한꺼번에 올려도 되고, 직접 입력해도 됩니다.
3. **2단계** — 판독 결과를 확인합니다. 잘못 읽은 글자는 여기서 고칩니다.
   글씨가 흐려 확신이 낮은 줄은 빨간 테두리로 표시됩니다.
4. **3단계** — 수급자별 기록을 확인·수정한 뒤 칸마다 **복사**를 눌러 케어포에 붙여 넣습니다.

### 메모 적는 법

한 줄에 `이름 - 내용` 형태로 적습니다. 같은 이름이 여러 번 나와도 되고, 순서가 섞여 있어도
수급자별로 알아서 묶어 줍니다. 여러 이름을 괄호나 세로선으로 묶고 내용을 하나만 적으면,
묶인 사람 모두에게 같은 내용으로 들어갑니다.

```
김손녀 ┐
김복순 ├ 점심을 모두 다 드심
이손자 ┘

이손자 - 노래 프로그램, 삶의 만족도 향상
김복순 - 평소보다 말을 많이 하심
```

## 개인정보

- 수급자 이름과 기록은 **이 기기의 브라우저에만** 저장됩니다. 별도의 서버가 없습니다.
- API 키도 브라우저에만 저장되며, 저장소에 올라가지 않습니다.
- 메모 사진과 글은 판독할 때만 Anthropic API로 직접 전송됩니다.
- 공용 PC에서 썼다면 **설정 → 저장된 내용 삭제**를 눌러 지우세요.
- 사진 파일(`*.jpg`, `*.png` 등)은 `.gitignore`로 막아 두어 실수로 커밋되지 않습니다.

## 비용

사용한 만큼 Anthropic API 요금이 청구됩니다. 모델은 설정에서 바꿀 수 있습니다.

| 모델 | 특징 |
|---|---|
| Opus 5.5 (기본) | 손글씨를 가장 잘 읽습니다. |
| Sonnet 5.5 | 중간. 글씨가 또렷하면 충분합니다. |
| Haiku 5.5 | 가장 저렴합니다. |

사진은 보내기 전에 긴 변 1568px로 줄여 전송량을 줄입니다.

## 로컬에서 띄우기

```bash
node dev-server.mjs
```

http://localhost:4173 으로 열립니다. (ES 모듈을 쓰므로 `index.html`을 파일로 직접 열면 동작하지 않습니다.)

## GitHub Pages 발행

이 폴더를 저장소에 올리고 **Settings → Pages → Source: Deploy from a branch →
`main` / `(root)`** 로 설정하면 됩니다. 빌드 과정이 없는 정적 파일이라 그대로 배포됩니다.

## 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 구조 |
| `app.css` | 모양 (밝은/어두운 테마, 휴대폰 대응) |
| `js/main.js` | 화면 동작, 사진 처리, 편집과 복사 |
| `js/api.js` | Anthropic API 호출과 오류 처리 |
| `js/prompts.js` | 판독·작성 프롬프트와 응답 형식 |
| `js/store.js` | 브라우저 저장 (설정, 작성 중인 기록) |
| `dev-server.mjs` | 로컬 미리보기 서버 (배포에는 쓰이지 않음) |
