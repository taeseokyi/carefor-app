# 요양급여제공 기록 도우미

**바로 쓰기 → https://taeseokyi.github.io/carefor-app/**

업무 중 손으로 적어 둔 메모를 사진으로 올리면, 수급자 개인별로
**신체활동 특이사항 · 인지관리 특이사항 · 상태변화 기록** 문장을 만들어 주는 웹 앱입니다.

만들어진 문장은 화면에서 바로 고칠 수 있고, **복사** 버튼을 눌러
[케어포](https://m.carefor.co.kr/share/care/care_list.php) 입력칸에 붙여 넣으면 됩니다.
앱이 케어포에 대신 입력하지는 않습니다.

## 세 가지 작동 방식

**⚙ 설정 → 작동 방식**에서 고릅니다.

### 노트북으로 (기본값, 추가 결제 없음)

집 노트북에서 백엔드를 돌리고, 거기 설치된 `claude` CLI가 처리합니다.
폰에서는 사진만 보내고 결과를 받아 봅니다. 설치와 실행은 [server/README.md](server/README.md)에 있습니다.

노트북 쪽은 한 번 설정해 두면 로그인할 때 알아서 뜹니다. 추가 설치 없이 집 Wi-Fi 안에서
`https://<노트북IP>:8787`로 붙고, 밖에서도 쓰려면 cloudflared 터널을 씁니다.

1. 앱 첫 화면의 연결 줄에 노트북 IP(또는 터널 주소)를 넣고 **연결**을 누릅니다.
   (토큰은 **⚙ 설정**에 한 번만 넣어 두면 됩니다.)
   처음 쓰는 폰이면 **인증서 설치 안내**가 펼쳐집니다. 안내대로 한 번만 설치하면 됩니다.
2. **1단계** — 사진을 올리고 **노트북으로 보내기**를 누릅니다.
3. **2단계** — 처리가 끝나면 목록에 쌓입니다. 눌러서 결과를 불러옵니다.
4. **3단계** — 확인·수정한 뒤 칸마다 **복사**를 눌러 케어포에 붙여 넣습니다.

주소가 바뀌면 첫 화면 연결 줄의 **주소 바꾸기**를 눌러 새 주소를 넣으면 되고,
최근에 쓴 주소 다섯 개는 입력칸에서 골라 쓸 수 있습니다.

노트북이 꺼져 있으면 쓸 수 없습니다. 그럴 때는 아래 두 방식 중 하나를 고르세요.

### Claude 앱으로 (추가 결제 없음)

Claude 구독만 있으면 됩니다. API 요금이 들지 않습니다.

1. **1단계** — **Claude에 보낼 프롬프트 복사**를 누릅니다.
2. Claude 앱에 붙여 넣고 **메모 사진을 함께** 보냅니다.
3. **2단계** — Claude가 보여 준 JSON을 복사해 붙여 넣고 **기록 불러오기**를 누릅니다.
4. **3단계** — 수급자별 기록을 확인·수정한 뒤 칸마다 **복사**를 눌러 케어포에 붙여 넣습니다.

### API 키로 (앱이 직접 처리)

Anthropic API 키를 등록하면 사진 업로드부터 문장 작성까지 앱 안에서 끝납니다.
쓴 만큼 API 요금이 듭니다.

1. **⚙ 설정** — API 키를 한 번 등록합니다.
2. **1단계** — 메모 사진을 올리고 **메모 판독하기**를 누릅니다.
3. **2단계** — 판독 결과를 확인합니다. 잘못 읽은 글자는 여기서 고칩니다.
   글씨가 흐려 확신이 낮은 줄은 빨간 테두리로 표시됩니다.
4. **3단계** — 위와 같습니다.

어느 쪽이든 수급자 명단을 적어 두면 이름 표기를 명단에 맞춰 줍니다.

## 휴대폰에 설치하기

앱 스토어나 APK 없이 홈 화면에 설치됩니다.

- **안드로이드** — 크롬으로 열고 메뉴 → **앱 설치** (또는 홈 화면에 추가)
- **아이폰** — 사파리로 열고 공유 → **홈 화면에 추가**

설치하면 주소창 없이 전체화면으로 뜨고, 아이콘도 생깁니다.
앱 파일은 캐시되므로 신호가 약한 곳에서도 화면은 바로 뜹니다.
(판독과 문장 작성은 인터넷이 필요합니다.)

### 문체를 바꾸고 싶을 때

**⚙ 설정 → 문체 지침**에 평소 말투로 적어 두면 기본 문체보다 먼저 적용됩니다.

```
문장은 두 줄을 넘기지 말 것
프로그램 참여는 신체활동 칸에 쓸 것
'관찰되지 않음' 대신 '없음'으로 끝낼 것
```

기관 지침이 바뀌거나 결과가 마음에 들지 않을 때 여기만 고치면 됩니다.
다만 메모에 없는 활동을 지어내게 하는 지침은 적용되지 않습니다.

### 메모 적는 법

한 줄에 `이름 - 내용` 형태로 적습니다. 같은 이름이 여러 번 나와도 되고, 순서가 섞여 있어도
수급자별로 알아서 묶어 줍니다. 여러 이름을 괄호나 세로선으로 묶고 내용을 하나만 적으면,
묶인 사람 모두에게 같은 내용으로 들어갑니다. (아래 이름은 가상의 예시입니다.)

```
홍길동 ┐
김영수 ├ 점심을 모두 다 드심
박순자 ┘

박순자 - 노래 프로그램, 삶의 만족도 향상
김영수 - 평소보다 말을 많이 하심
```

이름 앞의 `A`, `B`, `1`, `ㄱ` 같은 글자는 동명이인을 구분하려고 기관이 붙인 표시입니다.
메모에는 세 글자 이름만 적어도, **⚙ 설정 → 수급자 명단**에 적어 둔 표기(`A홍길동`)로 맞춰 줍니다.
명단에 같은 이름이 둘 있으면 짐작하지 않고 확인 표시를 남기니, 그런 분은 메모에도 표시를 붙여 주세요.

### 상태변화 기간

케어포의 상태변화기록은 하루치부터 길어야 일주일치까지 묶어 적는 칸입니다.
평소에는 비워 두고 그날 메모로 하루 기록을 만들고, 상태변화를 적는 날에만 **1단계**의
**상태변화 기간**에 시작일을 넣습니다. 그러면 상태변화 칸만 기록일까지의 기간을 요약하는 문장이 됩니다.

- 신체활동·인지관리 특이사항은 시작일을 넣어도 언제나 **기록일 하루**의 기록입니다.
- **노트북으로** 방식에서는 그 기간에 노트북이 먼저 만들어 둔 날짜별 기록을 참고해
  변화의 흐름(호전·악화·유지)을 적습니다. 참고할 기록이 없으면 이번 메모의 관찰만으로 씁니다.
  **Claude 앱으로**·**API 키로** 방식은 앞선 기록을 보관하지 않으므로 늘 이번 메모만으로 씁니다.
- 여러 날 메모를 한 번에 올릴 때는 메모 앞에 `월/일` 형태로 날짜를 적어 두세요.
  사진 메모라면 `10/21 점심 반만 드심`, 직접 입력칸이라면 `홍길동 - 10/21 점심 반만 드심`처럼 씁니다.
  날짜가 없는 메모는 기록일 것으로 보고, 기록일이 아닌 날 메모는 상태변화 칸에만 들어갑니다.

### 노트북이 어느 결과를 참고하나 — 확정 · 채택

**노트북으로** 방식에서 같은 날 같은 사람의 기록을 여러 번 만들었으면, 상태변화 기간을 묶을 때
그중 하나만 참고합니다. 우선순위는 **확정 → 채택 → 가장 나중에 만든 작업**입니다.

- **확정**: 결과 화면의 **노트북에 확정 저장** 버튼(결과 요약 아래와 맨 아래, 두 곳)을 누르면
  폰에서 고친 세 칸이 노트북의 그 작업에 덮어써지고 "확정" 표시가 붙습니다.
  케어포에 실제로 넣은 문장과 같아지므로 가장 먼저 참고합니다. 확정은 다른 작업을 채택해도 풀리지 않습니다.
- **채택**: 작업 목록에서 **불러오기**를 누르거나, 보낸 작업이 끝나 결과가 화면에 올라오면
  폰이 자동으로 노트북에 "이 결과를 썼다"고 알립니다. 따로 누를 것은 없습니다.
  같은 날 같은 이름이 든 다른 작업의 채택은 그때 풀립니다(확정된 작업은 제외).
- **가장 나중 작업**: 확정도 채택도 없으면 가장 나중에 만든 작업의 결과를 씁니다.

규칙은 **사람 단위**로 적용됩니다. 오전 작업에 홍길동·박순자, 오후 작업에 홍길동만 있고 오후 것을
확정했다면 홍길동은 오후 확정본, 박순자는 오전 작업 것을 참고합니다. 세 칸이 모두 빈 사람,
실패한 작업, 기록일 당일 작업은 참고하지 않습니다. 목록에서 **삭제**한 작업도 빠집니다.

작업 목록의 배지로 상태를 볼 수 있습니다: 완료(아직 쓰지 않음) · 채택 · 확정.

## 개인정보

- 수급자 이름과 기록은 **이 기기의 브라우저에만** 저장됩니다. 이 앱을 위한 공용 서버는 없습니다.
- **노트북으로** 방식에서는 사진과 메모가 집 노트북으로만 전송되고, 노트북이 `KEEP_DAYS`(기본 56일, 8주) 뒤 자동으로 지웁니다.
  노트북에는 토큰 없이는 접근할 수 없습니다.
- **Claude 앱으로** 방식에서는 이 앱이 사진을 어디로도 보내지 않습니다. Claude 앱에 직접 올리는 것만 전송됩니다.
- **API 키로** 방식에서는 판독할 때만 Anthropic API로 직접 전송됩니다. API 키는 브라우저에만 저장됩니다.
- 공용 PC에서 썼다면 **설정 → 저장된 내용 삭제**를 눌러 지우세요.
- 사진 파일(`*.jpg`, `*.png` 등)은 `.gitignore`로 막아 두어 실수로 커밋되지 않습니다.

## 비용

**노트북으로**와 **Claude 앱으로**는 구독 외에 드는 비용이 없습니다.

**API 키로** 쓰면 사용한 만큼 Anthropic API 요금이 청구됩니다. 모델은 설정에서 바꿀 수 있습니다.

| 모델 | 특징 |
|---|---|
| Opus 5.5 (기본) | 손글씨를 가장 잘 읽습니다. |
| Sonnet 5.5 | 중간. 글씨가 또렷하면 충분합니다. |
| Haiku 5.5 | 가장 저렴합니다. |

사진은 보내기 전에 긴 변 1568px로 줄여 전송량을 줄입니다.

## 로컬에서 띄우기

```bash
node dev-server.mjs
```

http://localhost:4173 으로 열립니다. (ES 모듈을 쓰므로 `index.html`을 파일로 직접 열면 동작하지 않습니다.)

## GitHub Pages 발행

`main` 브랜치의 루트에서 배포됩니다 (**Settings → Pages → Deploy from a branch → `main` / `(root)`**).
빌드 과정이 없는 정적 파일이라, `main`에 푸시하면 1~2분 뒤 반영됩니다.

## 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 구조 |
| `app.css` | 모양 (밝은/어두운 테마, 휴대폰 대응) |
| `js/main.js` | 화면 동작, 사진 처리, 편집과 복사 |
| `js/backend.js` | 노트북 백엔드와의 통신 |
| `js/api.js` | Anthropic API 호출과 오류 처리 |
| `js/prompts.js` | 판독·작성 프롬프트와 응답 형식 |
| `js/store.js` | 브라우저 저장 (설정, 작성 중인 기록) |
| `manifest.webmanifest` | 홈 화면 설치 정보 (이름, 아이콘, 색) |
| `sw.js` | 오프라인 캐시 |
| `server/` | 노트북에서 돌리는 백엔드 ([설명](server/README.md)) |
| `dev-server.mjs` | 로컬 미리보기 서버 (배포에는 쓰이지 않음) |
